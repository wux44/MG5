## Devlog

1. I think NavMesh is more useful when characters need to automatically find a path to a destination while avoiding obstacles. For example, in League of Legends, I think NavMesh makes more sense because players click on a location and their characters automatically find a path to get there. On the other hand, I think physics-based movement is better for games like Super Mario Bros., where players directly control the character's movement, including running and jumping, and gravity affects how the character moves.
2. The for loop goes through every bird in the _birds array. Vector3.Distance() calculates how far each bird is from the player. Based on the if statement, only birds within _interactDistance will run away, while birds farther away will stay.
